# translate スキル

## 使用するタイミング

- ユーザが「翻訳して」「英語にして」「日本語にして」「英訳」「和訳」などを要求したとき

## 手順

1. 翻訳先言語を判断する（「英語に」→ en、「日本語に」→ ja）
2. 入力テキストを指定言語に正確に翻訳する
   - 対応言語：日本語 (ja) と英語 (en) のみ
3. 翻訳結果のみを出力する（余分な説明は付加しない）

# summarize スキル

## 使用するタイミング

- ユーザが「要約して」「まとめて」「短くして」「N文で」などを要求したとき

## 手順

1. 入力テキストを読み込む
2. 指定された粒度・文数に従い要約を作成する
   - 「N文で」と指定された場合は必ず N 文で要約する
   - 「短く」「簡潔に」 → 1〜2文
   - 「中程度」または未指定 → 3〜5文
   - 「詳しく」「長く」 → 7〜10文
3. 要約結果のみを出力する（余分な説明は付加しない）

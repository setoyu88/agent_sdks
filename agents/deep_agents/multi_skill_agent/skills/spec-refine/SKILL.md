# spec-refine スキル

## 使用するタイミング

- ユーザが「仕様書を整理して」「要件を整理して」「スペックを改善して」などを要求したとき

## 手順

1. 入力された要件仕様書を分析する
2. 以下の構造に整理する
   - 目的
   - 機能要件
   - 非機能要件
   - 制約
   - ワークフロー
3. 曖昧語を排除し具体的な表現に置き換える
4. 過不足をチェックする
5. 明確化が必要な箇所があればユーザへ質問する
6. 改善仕様書を日本語で出力する
